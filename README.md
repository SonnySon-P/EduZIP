# An educational Deflate ZIP compressor implementation

I. Project Overview

Designed for high school students interested in data compression, this educational project offers a hands-on implementation of the Deflate algorithm. By focusing closely on the core concepts of LZ77 and Huffman coding, the project aims to help students bridge the gap between theoretical understanding and practical application.

II. Development Environment
1. Programming Language: Python
2. Editor / IDE: Visual Studio Code

III. How to Run the System
> [!Note]
> Please note that the system is currently limited to compressing a single, individual file.
1. Compress a file
```bash
python main.py c <File to Compress>
```
2. Decompress a file
```bash
python main.py d <File to Decompress>
```
